# PlacementOS web

Next.js App Router scaffold with React and Tailwind CSS. The current page is the generated starter; placement screens and API integration are planned.

From the repository root, after installing dependencies:

```sh
pnpm --filter web dev
pnpm --filter web lint
pnpm --filter web build
```

Development URL: `http://localhost:3000`. See [project status](../../docs/STATUS.md) and [local setup](../../docs/DEVELOPMENT.md).
